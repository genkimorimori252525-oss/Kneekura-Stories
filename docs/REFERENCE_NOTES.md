# 参考設計と独立実装

参考リポジトリ: https://github.com/NousResearch/autonovel

採用した**一般的な設計思想**:
- 世界観・人物・構成・文体・章本文・正史を別々に保管する。
- 企画 → 基礎設計 → 本文執筆という段階的な工程にする。
- 作品を生成した後も引継ぎ・設定の整合性・変更履歴を維持する。

意識的に採用しなかったもの:
- API呼び出し中心の自律型パイプライン。
- LLM審査員、点数付け、Elo、敵対的編集、自動改稿。
- 英語ファンタジーのための固定構成や固定表現禁止ルール。
- 強制Git reset、無制限の反復、画像／音声生成。

参考元には明示的なコードライセンスが確認できないため、**コードや文書のコピーではなく、要件からの新規実装**とする。引用された各種脚本技法も参考資料であり、著者の作品や文章を転載しない。
