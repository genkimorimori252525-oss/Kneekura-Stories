# 物語制作の参考ノート（非強制）

小説の読み味は総監督が決める。この文書は作家が選べる技法のリストであり、数値採点の基準ではない。

## 企画
複数の異なる方向から発想する。王道、静かな日常、心理劇、異色の構造、会話中心などを候補として広げる。AI自身で「無難な案だけ」に絞らない。

## 人物
人物に欲望、恐れ、習慣、人間関係、独自の言葉遣いを持たせる。変化する人物も、変化しない人物も、関係が変化するだけの人物もあり得る。全員を同じ英雄譚の型に押し込まない。

## 構成
シノプシスは結末まで記す。章構成の後、必要な場面の目的・行動・感情の動き・伏線をシーンカードにする。三幕構成、ビートシート、ストーリーサークル等は**必要な作品だけ**参考にする。

## 文体
語りの距離、視点人物の知識、沈黙、描写密度、文末の変化を作品ごとに選ぶ。心理描写を説明で語るか、行動で感じさせるかも作品の狙い次第。反復や比喩は自動的な欠点ではない。

## 改稿
総監督が指摘した箇所・理由を尊重する。気に入った場面の削除を先に提案するのではなく、変更範囲を限定する。改善前後の稿を保存する。

## モデルごとの癖
ClaudeもChatGPTも説明過剰、早すぎる和解、似た台詞、過度な整合性を生むことがある。ただし自動罰則にせず、執筆中の注意点として扱う。審査員AIは導入しない。
