# 開発計画・採用決定

## v0.1 — 実装済みの対象
- Claude CodeとChatGPTの共通制作ルール。
- 作品単位の独立フォルダと進捗管理。
- 6工程の提出・監督承認・差戻し・執筆バッチ継続。
- アイデア自動収集・選抜は削除せず**無期限休止**。監督の企画ブリーフを受け付ける。
- 軽監査で提出変更後の差戻し不能と完成原稿の章欠落検査を修正。
- 原稿の提出時ハッシュによる差し替わり検出。
- Python標準ライブラリによるCLI、ユニットテスト、CI。
- APIキー、外部モデル、外部DBへの依存なし。

## v0.2 候補（総監督が必要と判断したときのみ）
- 日本語向けの台詞呼称・時系列など、事実整合性だけの任意チェック。
- 章ごとの担当・競合を機械的に記録する機能。
- 承認済み稿の差分表示と、監督による部分改稿指示の補助。
- 独立した作品バックアップ／復旧コマンド。
- ChatGPTから直接編集しやすい標準化された引継ぎテンプレート。

## 後回し
- PDF/EPUB組版、表紙、朗読。
- 自動投稿、外部サイト連携、ブラウザ用UI。
- **不採用**: AI審査員、敵対的編集、Elo、自動改稿ループ、AI点数による自動破棄。

## 品質確認
本ツールのテストが検証するのは状態遷移やファイル保護などの**ソフトウェア上の正しさ**である。小説の良し悪しは総監督が判断する。
